## 이 페이지의 조정 기록

| 자리 | 조정 | 이유 |
|---|---|---|
| 페이지명 | 기대효과 → **Impact** | 「기대효과」의 영어 관용은 `Impact` 다. `Expected Effects` 는 번역체로 읽힌다 |
| 취업유발 / 생산유발 | `induced employment` / `induced output` | 산업연관분석의 표준 영어 용어다. 직역하면 경제 문서로 읽히지 않는다 |
| 「여 명」 | `+` (16,000+) | 카운터 뒤 단위 칸이 좁다. `approx.` 는 숫자 앞이라 쓸 수 없다 |
| 「0.9조원」 | 카운터는 `0.9 trillion won`, 본문은 `KRW 0.9 trillion` | 단위 칸 폭 제약. 통화 코드를 앞에 두는 규칙(`GLOSSARY.md` §7)은 본문에서만 지킨다 |
| 「~ 형성 / 구축 / 마련 / 제시」 | 명사구 또는 현재형 평서문 | 한국어는 동일한 명사화 꼬리를 반복하지만, 영어에서 `formation of / establishment of` 를 다섯 번 반복하면 읽히지 않는다 |
| 「친환경」 | `low-impact` (도시·가로) / `low-carbon` (이동) | `eco-friendly` 는 영어 마케팅에서 신뢰를 떨어뜨리는 말이 됐다. 무엇이 친환경인지에 따라 갈라 썼다 |
| 「메카」 | `center` | `mecca` 는 영어에서 종교적 함의 때문에 공적 문서에서 피한다 |
| 마무리 카피 | 한 문장을 **두 문장으로 쪼갰다** | 36자/줄 예산에서 한 문장으로 두면 5줄이 된다. 두 문장이면 4줄이고 결론이 분명해진다 |
