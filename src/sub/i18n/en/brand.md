> ⚠ 위 두 줄은 **칸을 따로 넣어야 했다.** 마크업이 `<dt>색상</dt><dd>3색 컬러 / …</dd>`

> (국문 5칸 vs 영문 2칸). 같은 이유로 최소 크기 · 여백 · 금지 행은 값에 `/` 가 하나뿐이라

### 소제목 — 영문 병기를 버린다

마크업이 `<h3 class="br-h3">기본 로고타입 <span>PRIMARY LOGOTYPE</span></h3>` 로
**한국어 제목 + 영문 라벨 병기**다. 영문판에서는 라벨(`<span>`)을 버리고 제목만 번역한다 —
둘 다 두면 같은 말이 두 번이고, 라벨을 제목 자리로 올리면 24px 전부 대문자가 되어
다른 제목과 어긋난다(버리는 일은 `pages-en.mjs` 의 `collapseEyebrow` 가 한다).

## 이 페이지의 조정 기록

| 자리 | 조정 | 이유 |
|---|---|---|
| 컬러 스와치 머리 | 「Indigo / 인디고」의 **국문 병기를 뺐다** | 영문판에서 `Indigo / Indigo` 가 되어 무의미하다. 스와치 안 글자는 흰색이고 대비가 이미 빡빡하므로(§11.43 — Mint 2.28 · Azure 3.33) 줄을 늘리지 않는 편이 좋다 |
| 「무게중심」 | `anchor` | `center of gravity` 는 물리 용어로 읽힌다. 브랜드 문서의 함의(신뢰·안정)를 `anchor` 가 옮긴다 |
| 「광채」 | `brilliance` | `glow` 는 약하고 `radiance` 는 과하다 |
| 「~로 끊어 쓰지 않는다」 | `never hyphenated as …` | 규정문이므로 금지형을 유지 |
| 「금지」 항목 | 명령형 동사 목록(`Rescale … rotate … recolor`) | 한국어 명사 목록을 그대로 옮기면(`change of proportion, rotation, …`) 규정이 아니라 개념 나열로 읽힌다 |
| 3색 설명 3단락 | 문장 구조를 유지하되 「~을 담았습니다 / ~를 상징합니다」를 `It stands for / It holds` 로 갈라 썼다 | 세 단락이 같은 꼬리로 끝나면 영어에서 복사한 문장처럼 읽힌다 |
| 「120px / 32mm 이상」 | `120 px / 32 mm or larger` | 단위 앞 공백(`GLOSSARY.md` §10) |

## ⚠ 브랜드 문서라 특별히 확인이 필요한 것

- **`B·CITY` 와 `B-CITY` 의 구분이 원문에 있다.** 워드마크(로고)는 가운뎃점 `B·CITY`,
  본문·URL 은 하이픈 `B-CITY` 다. 영문판도 **이 구분을 그대로 유지**했다.
- 「국문 표기 / 비시티」 행은 **한글을 그대로 남겼다.** 영문 독자에게도 한국어 표기 규정을
  보여 주는 것이 이 행의 목적이다. 로마자(`Bi-si-ti`)를 만들어 넣지 않았다.
- `Custom Geometric Sans` 는 서체의 **고유명이 아니라 설명**이다. 실제 서체명이 있으면
  그것으로 교체해야 한다 — **확인 필요.**
